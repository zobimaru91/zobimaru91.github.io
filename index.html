Chapter 02

Coordination

Coordination is part of design. It decides how a design actually gets built, and whether it works.

I moved deliberately into BIM coordination on the architectural side because I wanted to understand the building as a whole: how architecture, structure and MEP fit together, how information is managed, and how delivery is coordinated. The BIM years have made my architecture stronger, in technical documentation, in coordination with other disciplines and in authority compliance.

01Clash detection

I run the clash workflow end to end: clash matrix, detection cycles, clash dashboards and weekly resolution sessions with discipline leads, reported into progress and client meetings.

On CPK Airport, coordinating the facade and roof packages, my curtain wall plugin helped cut facade and roof clashes by ~20%.

02Federated models

I own the federation strategy and the federated model across architecture, structure and MEP through each IFC issue.

106 federated models across 18 buildings on Al Uqda, Phase 4 for PWA; model federation across 2 design teams on Palm Jebel Ali.

ISO 19650 delivery: Pre- and Post-Appointment BEP, MIDP and TIDPs, CDE structure and permissions, and QA/QC gates auditing LOD, naming and data classification against the client EIR at every issue.

On Al Uqda, 4 buildings approved Code A and the rest Code B, with no rejections; COBie generation and delivery on SSDL.

04Team leadership

I trained and mentored 20+ designers in Revit and Dynamo workflows, reducing repeat support requests by 20%, and trained 5 team members to competent Dynamo users at Walter AEC.

Executive-level BIM reporting to client leadership on OSE, Qiddiya.

Tools catalogue

Revit plugin · C# · Revit API · AI-assisted · free download

Faruk Syncinator 6000: one-button Sync & Relinquish

Problem
Syncing with Central and releasing worksharing ownership is a repeated, multi-step routine for every user on a workshared model.
What it does
One button on its own ribbon tab: Synchronize with Central, then Relinquish All Mine (borrowed elements, worksets and settings), then a "Sync complete" message. If Revit reports a problem, it shows the error and stops.
Impact
Deployed and in daily use across the 50-person practice at Focus Design Partners: one click instead of a multi-step routine.

Navisworks Manage plugin · C# · AI-assisted · free download

Faruk ClashReport 6000inator: clash report export

Problem
Navisworks' default clash report is hard to read for reviewers outside the BIM team.
What it does
Exports an HTML report with a picture per clash, plus a CSV for Excel, organised by clash test and clash group (whose scope). Each clash shows status, distance, location, description, assignee, comments, source files and the Revit Element ID of the instance itself, so Select by ID in Revit finds it. You pick the tests and statuses to export.
Impact
Built for reviewers and modellers who don't work in Navisworks: they can open the report, check their clashes and act on them without learning the software.

Navisworks Manage plugin · C# · AI-assisted · free download

Group Existing Clashes

Problem
When you take over a federated model that already has clash results, new clashes get lost among the existing ones, and regrouping them by hand in every test is slow.
What it does
One click in the Tool Add-ins tab: for every clash test in the open file, puts all clashes into one group with the name you type and the status you pick (New, Active, Reviewed, Approved or Resolved).
Impact
Existing clashes are parked in one step. After new NWC files are loaded and the tests re-run, anything that shows as New outside the group is a genuinely new clash to review.

Navisworks Manage plugin · C# · AI-assisted · free download

Clash Status Export / Import

Problem
Clash statuses agreed in one file, such as approvals in a client's NWD, don't carry into your own NWF.
What it does
Exports clash statuses from the source file to a .tsv, then imports them into your file by matching each clash on its pair of Revit Element IDs, and writes a log of what was matched.
Impact
Approvals are carried over instead of being re-entered clash by clash.
